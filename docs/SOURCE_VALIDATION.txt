NSP Controller 1.4.8 validation scope

- Reader starts when present and enabled in Server configuration, regardless of `ports`.
- Reader config parser ignores Server `ports`.
- Reader config hash excludes Server `ports`, so a Port-only Server change does not restart the Reader.
- CF-E718 scans hardware ports 1-4.
- Every valid raw detection is queued with `port_no`.
- Lane Calibration routes all detections from selected Readers; Edge filters ports.
- `controller_reader` does not store business `ports_json`.
- Readers UI is read-only and contains only identity, connection, status, detail and update time.
- Dynamic COM rebinding remains based on SDK SerialNumber.
- Static validation only; Windows MSBuild and physical Reader tests are still required.
